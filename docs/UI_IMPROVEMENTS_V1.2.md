# Vinfo UI Improvements V1.2

이 문서는 Vinfo 앱의 최신 UI/UX 개선 사항(V1.2)을 기록합니다.

## 1. 상단/하단 네비게이션 및 여백 개선

### 상단 플로팅 버튼 통일
- 기존의 가로로 긴 pill 형태의 `GlassTopBar`를 제거하고, 화면마다 필요한 버튼만 띄우는 **독립 원형 플로팅 버튼**으로 변경했습니다.
- 모든 상단 버튼에 `statusBarsPadding()`을 적용하여 펀치홀 카메라 및 시스템 상태바와 겹치지 않도록 안전 영역을 확보했습니다.

| 화면 | 상단 구성 |
|------|---------|
| **홈** | 상단 1/3 영역 중앙에 큰 "Vinfo" 타이틀 배치 + 우측 원형 설정 버튼 |
| **보관함** | 우측 원형 설정 버튼만 |
| **통계** | 우측 원형 설정 버튼만 |
| **상세** | 좌측 원형 뒤로가기 버튼 + 우측 원형 설정 버튼 |
| **설정** | 좌측 원형 뒤로가기 버튼만 |

### 하단 네비게이션 바 (FloatingBottomNavigation) 개선
- **선택 상태 시각화 강화**: 선택된 탭은 아이콘과 텍스트를 함께 감싸는 **알약형(pill) 연파랑 배경**을 적용하여 현재 위치를 명확히 했습니다.
- **미선택 상태 통일**: 선택 전후 레이아웃 변경으로 인한 어색함을 없애기 위해, 미선택 상태도 가로(Row) 구조로 통일하고 배경만 없도록 처리했습니다.

### 콘텐츠 하단 여백 확보
- 모든 화면의 스크롤 콘텐츠(`LazyColumn`) 하단 패딩을 `110dp` (상세 화면은 `160dp`)로 넉넉하게 설정하여, 마지막 콘텐츠가 플로팅 하단바에 가려지지 않도록 수정했습니다.

## 2. 화면별 기능 및 레이아웃 개선

### 홈 화면 (NowPlayingScreen)
- **타이틀 강조**: 화면 상단 1/3 영역을 활용해 "Vinfo" 앱 이름을 크고 대담하게(48sp, Bold) 중앙에 배치했습니다.
- **최근 감상 섹션 개편**: 앨범 이미지가 있던 기존 카드를 제거하고, **보관함 스타일의 텍스트 중심 카드(이미지 없음)** 2개만 보여주도록 단순화했습니다.
- **전체보기 연동**: "최근 감상" 섹션의 전체보기 클릭 시, 네비게이션 그래프를 통해 보관함(Archive) 탭으로 직접 이동하도록 연결했습니다.

### 상세 화면 (DetailScreen)
- **보관함에 추가 버튼**: 사용자가 분석 결과를 본 후 바로 저장할 수 있도록, 화면 맨 하단에 **"보관함에 추가" 고정 버튼**을 배치했습니다. 검은색 배경의 둥근 알약 형태로 강조했습니다.

### 보관함 화면 (ArchiveListScreen)
- **다중 선택 모드 (Long Click) 구현**:
  - 목록 아이템을 **꾹 누르면(Long Click)** 선택 모드로 진입합니다.
  - 선택 모드에서는 상단에 검색바/필터 대신 "N개 선택됨" 헤더와 "전체 선택/해제" 버튼이 나타납니다.
  - 각 아이템 좌측에 체크박스가 표시되며, 터치하여 다중 선택이 가능합니다.
  - 하단에 **취소 / 삭제** 액션바가 애니메이션과 함께 나타납니다. 삭제 버튼은 선택된 항목 수와 함께 표시되며, 클릭 시 실제 목록에서 제거됩니다.

---

## 3. 요약

V1.2 업데이트는 앱의 전반적인 **"플로팅(Floating)" 디자인 랭귀지**를 완성하고, **사용자 조작 편의성(보관함 추가, 다중 선택 삭제)**을 크게 높이는 데 집중했습니다. 모든 변경 사항은 Jetpack Compose의 선언적 UI와 Material 3 디자인 가이드를 준수하여 구현되었습니다.
