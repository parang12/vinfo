# Integration Rules

하나의 규칙: AI는 보조 도구이며, 모든 출력은 사람이 검증해야 한다.

- 코드 수용 기준
  - 테스트가 동반되어야 함 (새로운 동작을 도입하는 경우)
  - 보안/시크릿 관련 변경은 금지
  - 외부 API 키는 코드에 하드코딩 금지

- PR 체크리스트 (간단)
  - [ ] `flake8` 통과
  - [ ] `mypy` 통과
  - [ ] 유닛 테스트 추가/갱신
  - [ ] 변경점 설명 추가 (AI가 생성한 경우 표기)

- AI 사용 로그
  - AI가 생성한 주요 변경사항은 PR 설명에 `AI-ASSISTED` 태그를 추가
