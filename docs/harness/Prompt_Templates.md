# Prompt Templates

아래 템플릿은 AI에게 코드 리뷰, 테스트 생성, 버그 리포트 요약 등을 요청할 때 사용합니다. 요청 후 생성 결과는 반드시 사람이 검토하십시오.

- 코드 변경 리뷰

```
리포지토리: vinfo
파일: <경로/파일명>
변경 요약: <간단한 설명>
요청: 변경된 함수의 버그 가능성, 성능/안전성 문제, 타입/예외 처리 누락 여부를 점검해 주세요. 가능한 수정안과 테스트 케이스 예시를 제공해 주세요.
```

- 테스트 케이스 생성

```
리포지토리: vinfo
파일: <경로/파일명>
함수/메서드: <함수명>
요청: 경계값, 정상/예외 흐름을 포함한 pytest용 테스트 케이스 3개를 생성해 주세요. 모의 객체나 필요한 페이크 데이터를 명시해 주세요.
```

- 버그 리포트 요약

```
문제: <간단한 증상>
재현 단계: <스텝>
환경: OS, Python 버전, Android Studio 등
요청: 가능한 원인과 우선순위 높은 조사 항목, 임시 완화책을 제안해 주세요.
```
