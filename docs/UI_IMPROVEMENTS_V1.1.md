# Vinfo UI 개선 및 Pretendard 폰트 적용 내역 (v1.1)

본 문서는 사용자가 제공한 스크린샷 5장(홈, 상세, 보관함, 통계, 설정)을 기준으로 Vinfo Android 앱의 UI를 개선하고 Pretendard 폰트를 전역에 적용한 내역을 기록합니다.

## 1. 전역 디자인 시스템 개선

### Pretendard 폰트 적용
앱의 기본 폰트가 시스템 기본(Roboto)에서 **Pretendard**로 변경되었습니다.
- **적용 방식**: `res/font/` 디렉토리에 Pretendard TTF 파일(Regular, Medium, SemiBold, Bold, ExtraBold)을 추가했습니다.
- **Typography 업데이트**: `Type.kt`에서 `FontFamily`를 새롭게 정의하고, 자간(`letterSpacing`)을 약간 좁혀 현대적이고 깔끔한 타이포그래피를 구성했습니다.

### 공통 컴포넌트 개선 (`CommonComponents.kt`)
- **GlassTopBar**: 설정 화면 등에서 좌측 정렬 모드를 지원하도록 `centerTitle` 속성을 추가했습니다.
- **FloatingBottomNavigation**: 선택된 항목에 파란색 원형 배경과 흰색 아이콘을 적용하여 활성화 상태를 명확히 했습니다. (기존 pill 모양에서 이미지와 동일하게 개선)
- **GenreChip**: 기본 배경색을 연한 회색(`0xFFEEF0F8`)으로 변경하고, Primary/Secondary 구분이 가능하도록 개선했습니다.

## 2. 화면별 UI 개선 내역

### 홈 화면 (`NowPlayingScreen.kt`)
- **히어로 카드 (바이닐)**: 앨범 아트워크가 회전된 슬리브와 겹쳐진 형태의 바이닐 애니메이션 뷰를 구현했습니다. 우측 하단에 이퀄라이저 뱃지를 추가했습니다.
- **이퀄라이저 애니메이션**: 곡 정보 하단에 여러 높이의 막대로 구성된 파란색 이퀄라이저 바를 추가했습니다.
- **최근 감상 목록**: 앨범 썸네일 플레이스홀더를 어두운 톤으로 변경하고, 우측에 더보기(`MoreVert`) 아이콘을 추가했습니다.

### 상세 화면 (`DetailScreen.kt`)
- **점수 섹션**: "RYM 평점", "비평가 점수", "AI 일치도"를 3열로 가로 배치하고, 중간에 수직 구분선(`VerticalScoreDivider`)을 추가했습니다. AI 일치도는 파란색으로 강조했습니다.
- **장르 섹션**: 대표 장르(Primary)와 세부 장르(Secondary)를 구분하여 시각적 위계를 주었습니다.
- **가사 탭**: "원문"과 "번역"을 전환할 수 있는 pill 형태의 탭 컨트롤을 구현하고, 가사는 중앙 정렬 및 이탤릭체로 표시되도록 개선했습니다.
- **감상 가이드**: 아이콘과 텍스트를 나란히 배치하고 항목 사이에 가로 구분선을 추가했습니다.

### 보관함 화면 (`ArchiveListScreen.kt`)
- **검색바**: 모서리가 둥근 회색 배경의 단일 줄 텍스트 필드로 개선했습니다.
- **앨범 카드**: 이미지 없이 텍스트 중심의 카드로 변경했습니다. 좌측에 앨범명/아티스트/날짜를 배치하고, 우측 끝에 장르 칩 2개를 세로로 정렬했습니다.

### 통계 화면 (`GenreStatsScreen.kt`)
- **기간 선택 탭**: "30d", "90d", "1y" 탭을 회색 배경의 pill 형태로 구성하고, 선택된 항목만 파란색 배경이 되도록 개선했습니다.
- **도넛 차트**: 24dp 두께의 두꺼운 도넛 차트(회색 트랙 + 파란 진행률) 중앙에 평균 평점("42")을 크게 배치했습니다.
- **KPI 카드 (세로 배치)**: 중복된 카드를 제거하고, "가장 많이 들은 장르"와 "평균 평점" 카드를 세로로 나란히 배치했습니다. 각 카드 우측에 반투명한 대형 아이콘(헤드폰, 별)을 장식으로 추가했습니다.

### 설정 화면 (`SettingsScreen.kt`)
- **TopBar**: "설정" 텍스트를 좌측으로 이동시키고 설정 아이콘을 제거했습니다.
- **섹션 타이틀**: 각 카드 바깥 상단에 큰 글씨로 섹션 타이틀("권한 상태", "API 설정" 등)을 배치했습니다.
- **테마 설정**: 3개의 탭(라이트 모드, 다크 모드, 시스템 기본값)이 가로로 꽉 차게 배치된 pill 컨트롤로 개선했습니다.
- **데이터 관리**: "저장 기록 초기화" 텍스트 색상을 빨간색(`0xFFBA1A1A`)으로 변경했습니다.

## 3. 결과 요약
사용자가 제공한 레퍼런스 이미지 5장의 레이아웃, 여백, 컴포넌트 형태, 색상을 충실히 반영하여 전체 앱의 UI 완성도를 크게 높였습니다. 또한 Pretendard 폰트 적용으로 가독성과 세련미가 향상되었습니다.
